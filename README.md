# Umber

Five accessible React components you copy into your project. Button, Badge, Input, Card, Dialog.
No package to install in v1: open the site, copy the file, paste it next to your code. Each component
ships with its tests. Built with Next.js, React 19, Tailwind 4 and TypeScript.

**The cap:** Umber holds exactly five components until v2. Requests for a sixth go to the backlog in
[docs/PLAN.md](docs/PLAN.md).

## Working on it

```bash
npm install
npm run dev        # http://localhost:3005
npm test
npm run lint
npm run typecheck
```
